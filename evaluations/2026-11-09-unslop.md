## O que é
Skill para Claude Code, Codex e Antigravity que transforma UI "vibecoded" em interface desenhada sem mudar o produto: auditoria de sinais de slop com localização, triagem do tamanho da intervenção, direção em cinco linhas, nove passes ordenados (espaçamento → cor → ícones → copy → tipo → layout → detalhes → visuais → motion), checklist com teste do template. Extras técnicos: cópia de site vivo via Playwright e "story video" de ~10 s com redlines e morph de CSS (Playwright + ffmpeg).

## Classificação e decisão
| Item | Classe | Decisão |
|---|---|---|
| Método: triagem pesado/leve/sem slop (inclusive "não mexer em tela boa"), direção com caráter/mundo/momentos/assinatura, princípio "chrome quieto, riqueza nos momentos", ordem dos passes com justificativa, regras específicas de dashboard (hierarquia de gráficos, stat card = número, densidade de navegação), handoff quando só há URL ou screenshot | **B** | ABSORB_METHOD — incorporado em `web-design-engineer` como "Modo unslop" + reference |
| Valores fixos e proibições (4px, pesos 400–600, sem itálico, sem caixa alta, lucide) | C | Importados apenas como defaults condicionados à ausência de design system, conforme "Design constraints versus design dogma" |
| `snapshot.mjs`, `story.mjs`, geração de imagem paga | D | NÃO IMPORTAR — runtime externo; uso direto do original quando Playwright/ffmpeg existirem |

Quando houver conflito de gatilho com `design-taste-frontend` ou `impeccable`, invocar explicitamente `/unslop` para redesign de tela existente com cara de IA. Os scripts dependem de Playwright/ffmpeg e de acesso de rede ao site; no ambiente cloud do claude.ai podem não rodar.

## Segurança
Nada executado. `snapshot.mjs` abre a URL em Chromium e baixa CSS/assets da página para gravar HTML local; `story.mjs` sobe servidor HTTP em 127.0.0.1, chama `ffmpeg` via `execFileSync` e escreve/remove arquivos no diretório de saída. Sem credenciais nem telemetria observadas. Geração de imagem depende de MCP pago (fal, Replicate, OpenAI, Higgsfield) com confirmação antes do custo.

## Limites
Não lidos integralmente: `tokens.md`, `visuals.md`, `effects.md`, `refs.md` e o restante de `signs.md`. Nenhuma tela redesenhada para teste.
