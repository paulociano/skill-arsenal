# Content Production

## Objetivo

Levar uma ideia ou pauta até peças prontas para os canais necessários sem perder voz, prova, ownership ou capacidade real de produção.

## Skills candidatas

- content-matrix
- writing-quality
- social-post-review
- reels-scripting
- email-campaign-engineering
- niche-research
- voice-builder
- seo-research-audit

## Workflow

1. Defina objetivo, público, mensagem central, prova disponível, canais e deadline.
2. Reutilize brand/voice context existente. Não invente claims, clientes, métricas ou resultados.
3. Use content-matrix quando houver múltiplos formatos, ângulos ou etapas de campanha.
4. Para conteúdo factual/atual, use niche-research ou outra pesquisa adequada antes da redação.
5. Produza o formato com a skill específica de canal.
6. Use writing-quality para clareza, ritmo e coerência.
7. Use social-post-review quando houver publicação social a revisar.
8. Para campanhas recorrentes ou volume alto, aplicar operações editoriais:
   - owner por peça;
   - status claro;
   - fonte/prova do claim;
   - SME/revisor quando necessário;
   - capacidade semanal/mensal real;
   - estados Hold/Kill além de Draft/Approved;
   - data de última revisão para conteúdo evergreen;
   - política explícita para uso de IA quando relevante.
9. Adaptar/repurpose somente depois de fixar a mensagem central e as restrições do canal.
10. Arquivar aprendizado útil para o próximo ciclo quando existir superfície persistente.

## Brief mínimo para operação recorrente

- claim/ideia central;
- audiência;
- formato/canal;
- CTA;
- fontes/provas;
- owner;
- reviewer/SME se necessário;
- prazo;
- status;
- dependências.

## Regras

- Não produza canais que o usuário não pediu.
- Capacidade editorial é limitada pelo gargalo real, frequentemente review/SME e não apenas escrita.
- Não deixar conteúdo preso em "review" indefinidamente: definir owner e próxima ação.
- Não usar AI draft como evidência factual.
- Governança só entra quando escala/recorrência justificar; pedido isolado deve continuar leve.

## Integração

social-growth-engine usa esta stack na etapa de produção. Para SEO, combinar com seo-research-audit. Para voz persistente, voice-builder.
