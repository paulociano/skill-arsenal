# brand-creation-system

## Objetivo

Orquestrar o ciclo recorrente de criação ou reconstrução de uma marca sem reduzir branding a geração de logo.

## Skills candidatas

- brand-strategy
- brand-identity-system
- brand-logo-exploration
- color-psychology-context
- typographic-composition
- visual-composition-fundamentals
- brand-guidelines-authoring
- brand-asset-production
- design-system-governance
- verify-before-claim

## Workflow

1. **Ground** — entender negócio, audiência, categoria, evidências, assets e escopo.
2. **Strategy** — usar `brand-strategy` somente quando posicionamento e direção estratégica não estiverem suficientemente definidos.
3. **Identity directions** — usar `brand-identity-system` para construir poucas direções visuais contrastantes e obter escolha explícita.
4. **Logo** — usar `brand-logo-exploration` quando o símbolo/wordmark ainda precisar ser criado ou refinado.
5. **System refinement** — aprofundar cor, tipo, composição e elementos visuais somente onde agregarem valor.
6. **Guidelines** — materializar a identidade aprovada com `brand-guidelines-authoring`.
7. **Assets** — gerar e organizar derivados com `brand-asset-production`.
8. **Digital system** — usar `design-system-governance` quando a marca precisar virar tokens/componentes operacionais de produto.
9. **Verify** — checar consistência entre masters, guidelines, tokens e derivados antes de declarar conclusão.

## Gates humanos

Exigir escolha do usuário quando houver decisão real entre direções de identidade ou logo. Não automatizar gosto como se fosse validação objetiva.

## Modos

### Marca nova
strategy → identity directions → logo → guidelines → assets → digital system

### Rebrand
audit/context → strategy refresh se necessário → identity directions → logo refinement → guidelines → migration/assets

### Apenas logo
logo → asset production, sem forçar estratégia completa quando o briefing já for suficiente

### Manual de marca
inventory → guidelines → asset production, preservando identidade aprovada

## Regra de parcimônia

Nem toda tarefa precisa do ciclo inteiro. Use a menor cadeia que resolva o pedido. Não gerar brand book, tokens, motion ou social kit se não forem necessários.
