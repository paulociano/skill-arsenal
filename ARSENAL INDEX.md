# ARSENAL INDEX

Catálogo de roteamento do Skill Arsenal. Use este arquivo para selecionar candidatas antes de abrir `SKILL.md` ou `STACK.md` individuais.

## Como usar

1. Para `arsenal:` ou seleção automática, leia este índice primeiro.
2. Escolha a menor combinação que melhore materialmente a tarefa.
3. Abra somente os arquivos das skills/stacks selecionadas.
4. Skills listadas em uma stack são candidatas, não obrigatórias.
5. Este índice não substitui as instruções completas do recurso selecionado.
